
# Responsive Internship Board

## Project Overview
A responsive internship listing website built using HTML, CSS, JavaScript and JSON.

## Features
- Search internships by title, domain and skills
- Filter internships by domain
- Responsive layout for desktop, tablet and mobile
- Internship cards rendered dynamically using JavaScript
- Empty-result and error messages
- Keyboard-friendly form controls

## Technologies Used
- HTML5
- CSS3
- JavaScript
- JSON

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run index.html using Live Server.
4. Search and filter the internship listings.

## Data Notice
The sample internship records are fictional and are provided for demonstration.
